# 🤖 TechCode

![TechCode](./imagens/eva.png)

## 📚 Sobre o projeto

O **TechCode** é um site desenvolvido para apresentar um curso de tecnologia de forma **intuitiva, divertida e acessível**.

O projeto possui uma identidade visual moderna e utiliza a mascote **Eva**, uma robô criada para representar a TechCode.

A página inicial apresenta o curso e direciona o usuário para as demais áreas do site.

---

## 🌐 Páginas do site

O site possui as seguintes páginas:

- 🏠 **Home** — Página inicial do projeto
- 🛠️ **Serviços** — Informações sobre os serviços/cursos
- 🤝 **Parceiros** — Parceiros da TechCode
- ❓ **FAQ** — Perguntas frequentes
- 📝 **Blog** — Conteúdos e novidades
- 📩 **Contato** — Formas de entrar em contato
- 👥 **Sobre Nós** — Informações sobre a TechCode

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- HTML5
- CSS3
- Design responsivo
- Git e GitHub
